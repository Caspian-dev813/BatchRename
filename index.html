BatchRename

A lightweight batch file renaming tool. Rename hundreds of files with a custom prefix and sequential numbers — in one click.

⬇ Download Free
macOS Windows Universal Binary v1.0.0

Powerful, Simple

Everything you need to rename files in bulk — no learning curve required.

🏷️

Custom Prefix

Add any prefix to your file names. Perfect for organizing photos, documents, and archives.

🔢

Sequential Numbering

3-digit padded numbers (001, 002, 003...) with configurable starting point. Prefix before or after the number.

🎯

Extension Filter

Filter files by extension (e.g. jpg;png;gif) so you only rename what you want.

👀

Live Preview

See the old and new names side by side before committing. No surprises.

💾

Auto Backup & Restore

Files are backed up automatically before renaming. One click to restore if something goes wrong.

🔧

Permission Repair

macOS feature: auto-fix file ownership when files belong to other users (e.g. mounted ISOs).

How to Use

Four simple steps to rename your files.

Browse

Select the folder containing the files you want to rename.

Configure

Enter prefix, start number, and optional extension filter.

Preview

Review the new names in the preview table.

Execute

Click execute. Restore anytime if needed.
